# Books in English Tbilisi — каталог наличия

Страница: https://miraclepo23.github.io/books-in-english/

- `index.html` — страница (не редактируется вручную).
- `data.js` — данные каталога; собираются из Google Таблицы «Каталог книг» скриптом `build/build_catalog.py`.
- `img/` — обложки из Instagram (первый запуск), `gallery/` и `video/` — фото и видео из папки «Фото книг» в Google Диске.
- `build/desc.json` — автоматически найденные описания книг.

Обновляется автоматически раз в час задачей Claude.
